Guardrails

The server enforces the rules, not the AI.

A prompt hidden in a plugin readme or a web page can't talk its way past these limits. They are checked by PressBridge before anything runs.

Allowed Upkeep you'd do yourself

  • wp plugin update akismetOn sites you mark for maintenance
  • wp core update && update-dbCore updates, last
  • wp cache flushAfter theme changes
  • wp core verify-checksumsSpot hacked core files
  • edit_file header.phpBacked up and PHP-checked
  • search-replace --dry-runPreview before migrating

Refused Anything that could sink a site

  • wp eval / eval-file / shellNo arbitrary PHP
  • wp db query / export / importNo raw SQL
  • wp config get DB_PASSWORDSecrets stay secret
  • wp user create --role=administratorNo new admins
  • wp option update siteurlProtected options locked
  • read_file ../../etc/passwdNothing outside the site folder
What's inside

Built for people who look after other people's websites.

One-call undo

Every edit, move and delete copies the original outside the webroot first. Claude tells you the backup ID; restore_backup puts it back.

No white screens

PHP files are checked with php -l before they're saved. A missing semicolon in functions.php never goes live.

Per-client permissions

Read-only for the bistro, full maintenance for staging, edits on the agency site. Set in one YAML file.

Secrets hidden everywhere

wp-config, .env, SQL dumps, keys and .git don't show up in listings, searches or reads. At any folder depth.

Audit log

Every call is written to a JSON Lines log: time, site, tool, arguments, result. Useful when a client asks what changed.

Your server, your data

Runs in Docker on the same machine as the sites. Automatic HTTPS, bearer tokens, or SSH with no open port at all.

New · PressBridge Watch

A night shift for every site you look after.

Every night, Watch compares each site with the night before. A new administrator, a PHP file in uploads, a changed core file: you hear about it before your client does.

  • New administrator accountsThe first thing most attackers create.
  • PHP files in the uploads folderAlmost always a web shell.
  • Backdoor-like codeeval(base64_decode(…)), code run from $_POST, images loaded as PHP.
  • Core files changed without an updatePlus wordpress.org checksums for core and plugins.
  • Risky settingsOpen registration with an admin default role, a changed site address.
  • Sites that crashA PHP fatal error means the site is probably down.

Plugin updates and changes made through PressBridge are recognised, so they don't wake you up. On quiet weeks you get a short all-clear, so you know Watch is running.

Setup

About ten minutes on a server you already run.

You need SSH access and Docker on the server where your WordPress sites live. No Docker? A plain Python install over SSH works too.

  1. List your sites

    sites:
  acme:
    root: /var/www/acme/public_html
    mode: write
    wp_profile: maintenance
  bistro:
    root: /var/www/bistro/htdocs

  2. Start it

    echo "PB_TOKEN=$(openssl rand -hex 32)" > .env
echo "PB_DOMAIN=mcp.agency.com" >> .env
docker compose --profile tls up -d

    Caddy gets an HTTPS certificate automatically.

  3. Connect Claude

    claude mcp add --transport http \
  pressbridge https://mcp.agency.com/mcp \
  --header "Authorization: Bearer $PB_TOKEN"

    Claude Desktop setup is in the install guide.

Questions

Before you buy

Does my site's content go through your servers?

No. PressBridge runs on your server. Claude connects to it directly. The only party that sees the files Claude reads is the AI provider you already use.

Which hosting does it work on?

Any Linux server where you have SSH and can run Docker or Python: VPS, dedicated, RunCloud, Ploi, SpinupWP, GridPane, Coolify and similar. Shared hosting without SSH is not supported.

Does it work with Claude Desktop, or only Claude Code?

Both. Claude Code connects over HTTPS with a token. Claude Desktop connects over SSH or through a small local bridge; the install guide has copy-paste configs for each. Other MCP clients like Cursor work the same way.

What if Claude breaks something anyway?

Every file change has a backup outside the webroot and can be restored in one call. Database changes (plugin updates, option updates) are not covered by those backups, so keep your normal database backups running. The updates skill updates one plugin at a time and stops at the first error.

Can I use it for client sites?

Yes. Every paid plan covers unlimited sites, including sites you maintain for clients. You can't resell PressBridge itself.

What's the difference between Agency and Agent?

Agency is a one-time license for the tools Claude uses to work on your sites. Agent is monthly and adds Watch, which checks every site every night and alerts you when something changes that shouldn't have.

Does Watch need an Anthropic API key?

No. The checks and alerts work without one. With a key, Claude also investigates what was found and explains it. That usage is billed to you by Anthropic, and only happens on nights with findings.

What happens if I cancel Agent?

Your Agent license ends with the paid period, so Watch and the Agent edition stop. To keep the tools without Watch, buy a one-time Solo or Agency license.

Is the code open?

You get the full Python source with every paid plan, and the Free edition is MIT-licensed on GitHub. Read every line before you run it on a client server.
